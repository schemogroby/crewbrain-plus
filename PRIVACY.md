# Datenschutzerklärung – Zeiterfassung Plus für CrewBrain

Stand: 27.10.2026

**Kurz gesagt: Die Erweiterung erhebt, speichert und überträgt keine personenbezogenen Daten.**

## Was die Erweiterung tut

Die Erweiterung läuft ausschließlich auf Seiten unter `*.crewbrain.com`. Sie liest die dort bereits angezeigten Zeiterfassungsdaten (Anwesenheit, Pausen, Aufgaben) direkt im Browser aus. Daraus zeigt sie zusätzliche Hilfen an: farbige Hinterlegung, Zusammenfassung, Zeitvorschläge und eine bessere Suche.

## Was gespeichert wird

Lokal im Browser (`localStorage` der CrewBrain-Seite) liegen nur diese Einstellungen:

- die gewählte Zoomstufe,
- ob das Overlay an- oder ausgeschaltet ist,
- die Namen der zuletzt gewählten Aufgaben, für die Schnellauswahl.

Diese Daten verlassen den Browser nicht.

## Was nicht passiert

- Es werden keine Daten an den Entwickler oder an Dritte gesendet.
- Es gibt keine Analyse-, Tracking- oder Werbedienste.
- Die Erweiterung speichert keine Zeiten in CrewBrain. Gespeichert wird nur, wenn du selbst in CrewBrain auf „Speichern“ klickst.
- Die Erweiterung lädt keinen Code von außen nach.

## Hinweis

Dies ist ein inoffizielles Hilfsprogramm. Es steht in keiner Verbindung zum Anbieter von CrewBrain.
